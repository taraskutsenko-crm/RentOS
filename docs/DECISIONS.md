# RentOS Decision Register

A concise index of major repository decisions. Full rationale for
schema/architecture-level decisions lives in the linked ADRs
(`docs/adr/`) — this file does not repeat their content, only points to
it, plus records the many smaller decisions that never warranted a full
ADR of their own.
